VobSub → SRT

source on GitHub

Turns DVD/Blu-ray bitmap subtitles (.idx + .sub) into text subtitles (.srt), keeping italics and line breaks. Letters are matched against a shared memory of fonts; a font nobody has uploaded before is read once by a vision model and is then known for everyone.


  

  


  

    How it works, what to expect
    
    
      
  • Known font: a few seconds, no vision model involved. This is the case for every font that was
          uploaded before (currently ? fonts in memory).
    • 
      
  • New font: the converter asks a vision model about the cues that teach the most new letters, learns
          their shapes, and reads the rest itself. Typically 50–200 requests, a couple of minutes; each request is
          only made once per letter shape, never per cue.
    • 
      
  • Accuracy: letters are matched pixel-exactly, so text is reproduced literally (typos included).
          Where the vision model and the memory disagree, the memory wins once it has enough evidence. Pixel-identical
          I/l are decided by dictionaries.
    • 
      
  • Unknown glyphs that could not be learned (budget used up, no vision model) are written as
          � so you can find them; the count is shown after the conversion.
    • 
      
  • Limits per address: ?. Jobs run one after another; the queue position is shown.
    • 
      
  • Data: uploads are deleted the moment the job ends, the SRT after one hour. Only the shapes of the
          letters (the font, with no words or text) are kept in the shared memory. The memory is published with
          the source code.
